# GTA916 Audience and Income Strategy

This strategy aligns server operations and content operations to build a durable GTA916 audience funnel.

## Audience hypothesis

Primary audience:

- GTA players in the Sacramento/916 region
- players outside 916 who like region-themed RP communities

Secondary audience:

- FiveM beginners looking for active, story-driven communities

## Positioning

GTA916 should feel like:

- locally flavored RP (916 references, neighborhoods, community lore)
- consistent admin quality and low-toxicity onboarding
- creator-friendly server events that produce clip-worthy moments

## Channel roles

- `faceless-youtube`: discovery engine (search + suggested feed reach)
- `streaming`: trust engine (live proof of culture and admin quality)
- `marketing-materials`: conversion support (campaign creative, promos, announcements)

## Revenue model phases

Phase 1 (now):

- audience growth, watch-time, Discord join rate, return player rate

Phase 2:

- compliant paid perks via approved store integration
- value-centered supporter tiers (non pay-to-win priority)

## KPI baseline (first 60 days)

- content KPIs: views, retention, CTR, clips reused
- community KPIs: Discord joins/week, onboarding completion
- gameplay KPIs: unique players, avg session length, repeat visits
- conversion KPIs (when enabled): package page visits, checkout conversion

## Content-signal loop

1. run themed in-server events
2. capture moments (wins/fails/chases/community stories)
3. repurpose into shorts, compilations, and live hooks
4. route viewers to Discord/server status pages
5. feed player behavior back into next content themes
