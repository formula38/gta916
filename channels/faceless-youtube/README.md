# Faceless YouTube Workflow

Purpose: build discoverability for GTA916 without requiring on-camera content.

## Content types

- Shorts: funny fails, police chases, event highlights
- Long-form: weekly server stories, "best moments", update recaps
- SEO topics: GTA RP tips, 916-themed RP stories, FiveM setup/build logs

## Production pipeline

1. Collect clip candidates from live sessions/events.
2. Write script hooks (`hook`, `conflict`, `payoff`, `CTA`).
3. Edit with consistent branding package.
4. Publish with title/thumbnail variants.
5. Track retention and iterate next batch.

## CTA strategy

- Primary CTA: join community/Discord
- Secondary CTA: watch next video in playlist
