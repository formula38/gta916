# Streaming Workflow

Purpose: build trust and community depth through live sessions.

## Stream blueprint

- pre-stream: event goals and moderation assignments
- live blocks: intro, feature segment, event/challenge, community Q&A
- post-stream: clip extraction and repurpose queue

## Clip repurposing

1. mark timestamps during stream
2. cut highlights into short vertical clips
3. route clips to faceless YouTube backlog
4. create weekly compilation candidates

## Operational notes

- keep consistent schedule (same days/times)
- maintain mod/admin visibility during live sessions
- prioritize interaction moments that convert viewers to community members
