# Marketing Materials Workflow

Purpose: generate reusable campaign assets that support community growth.

## Asset categories

- launch/update posters
- event promos
- recruitment posts (players/staff)
- social cutdowns/ad variants

## Higgsfield MCP workflow (planned)

1. define campaign brief (audience, objective, CTA)
2. generate multiple visual/copy variants
3. review for brand and policy compliance
4. publish winning variants to target channel
5. archive top-performing assets for reuse

## Naming and organization

- keep assets grouped by campaign and date
- include channel target in filename
- track performance notes next to each campaign batch
